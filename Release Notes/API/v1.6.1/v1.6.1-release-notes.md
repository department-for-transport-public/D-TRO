# Digital Traffic Regulation Orders (D-TRO)

## Release Notes - `v1.6.1`

**Release Date:** 14 September 2026  
**Prepared by:** Ben Pauley

`v1.6.1` of the D-TRO service was released to the production environment on 14 September 2026. This patch release includes the following changes.

## Changelog

- Removed height validation of bridge height restrictions

## Removed Bridge Height Restriction Height Validation

`v1.6.0` introduced functionality for publishing bridge height restriction data to the service. As part of the submission process, validation was in place to ensure that the the given imperial height data matched the givem metric height data (rounded down to the nearest inch). TSRGD states that both the metric and imperial heights are calculated indepdendently of one another, with different rounding rules. As a result, this validation has been removed.
