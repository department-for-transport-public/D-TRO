# Digital Traffic Regulation Orders

## API Release Notes - `v1.6.0`

**Release Dates**

![INT](https://img.shields.io/badge/Integration-11th%20September%202026-red?style=flat-square)

![PROD](https://img.shields.io/badge/Production-11th%20September%202026-blue?style=flat-square)

`v1.6.0` of the D-TRO API was released to the integration and production environments on the production environment on 11<sup>th</sup> September 2026. This minor release introduces a number of new capabilities and service improvements.

## Changelog

- Support for publishing and consuming bridge height restriction data
- Spatial search capability for D-TRO records
- Improved searchability of speed limit orders
- General service performance improvements and bug fixes
