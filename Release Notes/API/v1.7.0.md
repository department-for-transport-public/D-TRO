# Digital Traffic Regulation Orders

## API Release Notes - `v1.7.0`

**Release Dates**

![INT](https://img.shields.io/badge/Integration-3rd%20November%202026-red?style=flat-square)

![PROD](https://img.shields.io/badge/Production-1st%20December%202026%20(TBC)-blue?style=flat-square)

`v1.7.0` of the D-TRO API was released to the integration environment on 3<sup>rd</sup> November 2026, and is scheduled to be released to the production environment on 1<sup>st</sup> December 2026. This minor release includes the following changes.

## Changelog

- Expired, temporary D-TROs can be omitted from search results via the `/search` endpoint through use of the `includeExpired=false` query parameter. In the future, this behaviour will be the default, and retrieving expired temporary TROs will be opt-in via `includeExpired=true`
- Semantic validation error messages have been overhauled, with messages now being clearer and offering a more direct explanation of the cause of errors. Additionally, the rule ID is returned in the response, allowing for cross-referencing against the validation document
- Support for retrieval of D-TROs with geometry in WGS84 format in `/dtros/<id>` endpoint. This endpoint takes an optional query parameter, `srid` to allow retrieving D-TROs in the specified CRS. Currently supported values are `srid=27700` (BNG) and `srid=4326` (WGS84). If the parameter is omitted, data is returned in BNG. UNrecognized CRS values yield an error. Please note support for BNG extends to data consumption only; publishers are required to continue to use BNG format when submitting data
- Updating a D-TRO with the exact same content is now idempotent and yields an `HTTP 200 OK` response rather than an `HTTP 409 Conflict`. Updating a D-TRO with the same content as an existing D-TRO continues to yield `HTTP 409 Conflict`
- Fixed a bug where a D-TRO could not be created when the same content already existed on a deleted D-TRO
- General performance and stability improvements to the service, specifically around D-TRO submission and searching
