# Digital Traffic Regulation Orders

## Data Model Release Notes - `v3.5.0`

**Release Dates**

![INT](https://img.shields.io/badge/Integration-21st%20October%202025-red?style=flat-square)

![PROD](https://img.shields.io/badge/Production-18th%20November%202025-blue?style=flat-square)

`v3.5.0` of the D-TRO Data Model was released to the integration environment on 21<sup>st</sup> October 2025, and the production environment on 18<sup>th</sup> November 2025. This minor release includes the following changes to the data model.

## Changelog

- removed `conditions` as a property of `regulation`
- added `publicRightOfWayClosure` to `regulationType` enum
- changed spelling of `cubicCentimeters` to `cubicCentimetres` in `unitOfMeasureEnum`
- added `publicHolidayName` object to `specialDayType` object
