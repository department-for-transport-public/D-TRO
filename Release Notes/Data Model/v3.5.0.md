# Digital Traffic Regulation Orders

## Data Model Release Notes - `v3.5.0`

**Release Dates**

![INT](https://img.shields.io/badge/Integration-29th%20September%202025-red?style=flat-square)

![PROD](https://img.shields.io/badge/Production-27th%20October%202025-blue?style=flat-square)

`v3.5.0` of the D-TRO Data Model was released to the integration environment on 29<sup>th</sup> September 2025, and the production environment on 27<sup>th</sup> October 2025. This minor release includes the following changes to the data model.

## Changelog

- added `informationUpdate` to `actionType` enum
- added support for modelling emissions-related regulations
- added support for modelling electric vehicle charging conditions
- added other condition options within condition sub-model
- added support for MULTIPOINT, MULTILINESTRING and MULTIPOLYGON geometries
- added `dialARide` to `vehicleUsage` enum
- changed the data type of `expectedDuration` from integer to duration
- removed support for elementary street units (ESUs)
- added national speed limit profile for speed limit regulations
- removed `conditions` as a property of `regulation`
- added `publicRightOfWayClosure` to `regulationType` enum
- changed spelling of `cubicCentimeters` to `cubicCentimetres` in `unitOfMeasureEnum`
- added `publicHolidayName` object to `specialDayType` object
