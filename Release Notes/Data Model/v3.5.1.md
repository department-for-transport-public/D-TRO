# Digital Traffic Regulation Orders

## Data Model Release Notes - `v3.5.1`

**Release Dates**

![INT](https://img.shields.io/badge/Integration-5th%20December%202025-red?style=flat-square)

![PROD](https://img.shields.io/badge/Production-9th%20January%202026-blue?style=flat-square)

`v3.5.1` of the D-TRO Data Model was released to the integration environment on 5<sup>th</sup> December 2025, and the production environment on 9<sup>th</sup> January 2026. This patch release includes the following changes to the data model.

## Changelog

- added `heavyGoodsVehicle`, `motorVehicle`, `publicServiceVehicle` and `schoolBus` to the `vehicleType` enum
- added `miscFootpathClosure` as a new `regulationType`
- removed `publicRightOfWayClosure` from `regulationType`, as it is considered a duplicate of `miscPROWClosure`
- updated `coastGuardVehicle` in the Data Model to `coastguardVehicle`, to reflect the schema
- removed duplicate `electric` entry from `fuelType` enum
- added tighter validation for datetime formats, where hours, minutes and seconds are all mandatory
- added `payloadType`, `fuelType`, `vehicleEquipment` and `vehicleType` `vehicleCharacteristics` extension mechanisms
- corrected inconsistency of multiplicity of `vehicleType` in the Data Model (zero-to-many) to match the schema (one-to-many)
