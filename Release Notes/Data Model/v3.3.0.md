# Digital Traffic Regulation Orders

## Data Model Release Notes - `v3.3.0`

**Release Dates**

![INT](https://img.shields.io/badge/Integration-28th%20October%202024-red?style=flat-square)

![PROD](https://img.shields.io/badge/Production-25th%20November%202025-blue?style=flat-square)

`v3.3.0` of the D-TRO Data Model was released to the integration environment on 28<sup>th</sup> October 2024, and the production environment on 25<sup>th</sup> November 2025. This minor release includes the following changes to the data model.

## Changelog

- moved `timeValidity` from the `regulation` object to be a child of `condition`
- added `kerbsideSingleRedLines` and `kerbsideDoubleRedLines` to the `regulationType` enum
- added the ability to model diversion routes
