# Digital Traffic Regulation Orders

## Data Model Release Notes - `v3.4.0`

**Release Dates**

![INT](https://img.shields.io/badge/Integration-13th%20May%202025-red?style=flat-square)

![PROD](https://img.shields.io/badge/Production-10th%20June%202025-blue?style=flat-square)

`v3.4.0` of the D-TRO Data Model was released to the integration environment on 13<sup>th</sup> May 2025, and the production environment on 10<sup>th</sup> June 2025. This minor release includes the following changes to the data model.

## Changelog

- migrated the schema from pascal case to camel case
- moved `maximumAccessDuration` and `minimumTimetoNextEntry` from `permitSubjectToFee` object to `permitCondition` object
- added additional enumeration values to `regulationType`, `vehicleType` and `permitType`
