# Digital Traffic Regulation Orders

## Data Model Release Notes - `v3.4.1`

**Release Dates**

![INT](https://img.shields.io/badge/Integration-15th%20July%202025-red?style=flat-square)

![PROD](https://img.shields.io/badge/Production-12th%20August%202025-blue?style=flat-square)

`v3.4.1` of the D-TRO Data Model was released to the integration environment on 15<sup>th</sup> July 2025, and the production environment on 12<sup>th</sup> August 2025. This patch release includes the following changes to the data model.

## Changelog

- added `maxStayNoReturn` attribute for all regulations (previously limited to permits only)
- extends the “Extension Enumeration” works across all of the following enumerated list: `permitType`, `paylodType`, `vehicleUsageType`, `emissionsClassificationEuroType`, `fuelType`, `vehicleEquipmentType` and `vehicleType`
- fixed a bug preventing submission of consultation orders
- added the following vehicle types to the `vehicleType` enum: `poweredVehicleUsedByDisabledPeople`, `emergencyAndIncidentSupportVehicle` and `diplomaticVehicle`
- added the following fuel type to the `fuelType` enum: `electric`
- added the following regulation types to the `regulationType` enum: `kerbsideRedRouteBusStopClearway`, `miscCycleHireParking` and `miscCycleParking`
