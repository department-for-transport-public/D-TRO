Events

Retrieve D-TRO event history

Retrieve a list of D-TRO events (e.g., creations, updates, deletes) that match a given search criteria. Note: Pagination is applied at the D-TRO level, not the event level. For example, pageSize = 50 means the service retrieves 50 D-TROs and expands them into events (each D-TRO may have multiple events). The totalCount field in the response is hardcoded to -1 to reflect that it no longer reflects events.

None
